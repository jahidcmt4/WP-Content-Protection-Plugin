== Description ==

Disabled Source, Disabled Right Click, and Content Protection is a very simple plugin to Protect your Website Content, Disable view page source(Ctrl+U), Disable Right Click, Disable F12 functional key, and Disable save the page(Ctrl+S). The special thing is for you to allow or disallow your post comments/review section.

The plugin is called copy content protection. It is very easy to use and install. This plugin protects content both on PC and mobile devices. Our latest features block IP Addresses.

<strong> Activate Disabled Source, Disabled Right Click, and Content Protection plugin and check those features by opening your website on a private/Incognito window/By Logout </strong>

== Installation ==

1. Install Disabled Source, Disabled Right Click and Content Protection by uploading the `disabled-source-disabled-right-click-and-content-protection` directory to the `/wp-content/plugins/` directory.
2. Activate Disabled Source, Disabled Right Click and Content Protection through the `Plugins` menu in WordPress.
3. You can change this option any time you want by going to the `Disabled Settings` Admin Menu.
4. Activate Disabled Source, Disabled Right Click and Content Protection plugin and check your website on private/Incognito window.
